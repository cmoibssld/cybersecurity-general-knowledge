# PISCINE CYBER - 42

This repository is an addition of every project realised during the Cybersecurity Piscine of 42. The aim of this Piscine is, after Common Core completion, get a first glance at some of cybersecurity challenges (web, cryptography, reverse engineering...) during one-day duration projects.

The projetcs are completed in this order:
- arachinada (web)
- ft_otp (OTP)
- ft_onion (web)
- Reverse me (reverse)
- Stockholm (malware)
- Iron Dome (malware)
- Inquisitor (network)
- Vaccine (web)

For each, in the correct repo, you will find a README explaining the goal and aim of the project.
Most of the project where completed using Rust.
